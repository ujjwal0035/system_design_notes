# Parking Lot Management System - Low Level Design

## Problem Statement

Design a system to manage a multi-level parking lot that supports different types of vehicles, automated ticketing, and real-time availability tracking.

## Core Requirements

### 1. Multi-Level Support
- The parking lot has multiple floors

### 2. Vehicle Diversity
- Support for Motorcycles, Cars, and Large Trucks/Buses

### 3. Spot Allocation
- A vehicle should be assigned the nearest available spot suited for its size

### 4. Ticketing & Payment
- Issue a ticket with a timestamp upon entry
- Calculate fees upon exit based on duration and vehicle type

### 5. Real-time Dashboard
- Display the number of free spots per floor
